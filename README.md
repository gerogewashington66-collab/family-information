# 刘家 · 生日温馨站

根据「刘家生日信息表」制作的静态家庭生日网站，支持农历生日自动换算、当日提醒与一年时光轴。

## 功能

- **农历 → 公历**：按当年自动换算每位家人的农历生日
- **当日提醒**：生日当天顶部显示醒目祝福横幅
- **桌面通知**：可点击页脚按钮开启浏览器通知（需允许权限）
- **近期生日**：展示未来 14 天内即将过生日的家人
- **分代展示**：第一代 / 第二代 / 第三代卡片分组
- **一年时光轴**：页面底部横向数轴，串联全年各成员公历生日与姓名

## 使用

1. 用浏览器直接打开 `index.html`，或
2. 本地起一个静态服务后访问，例如：

```bash
npx serve .
```

## 数据

成员信息在 `data.js` 中，格式与 Excel 表一致（姓名、农历年月日、代际）。修改后刷新页面即可。

## 说明

- 生日判断以**当年公历中对应农历月日**为准
- 需联网加载 `lunar-javascript` 农历库与 Google 字体
